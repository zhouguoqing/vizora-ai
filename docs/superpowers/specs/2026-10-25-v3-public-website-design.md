# Vizora AI V3 官网改版设计

日期：2026-10-25  
状态：MVP 已实现并完成本地前端验证  
参考：<https://vizora-ai-home-guoqing-1025.aglowbloom2048.chatgpt.site/>

## 目标

以用户提供的参考站为视觉基准，重新设计 Vizora AI V3 全部公开官网页面，呈现清晰、可信、面向业务场景的 AI 大屏设计与开发产品。保留现有真实业务能力、API 合同、路由和交互，不以视觉演示暗示尚未接通的能力。

## 范围与约束

### 改版页面

- `/` 首页
- `/features` 产品能力
- `/solutions` 应用场景
- `/templates` 模板市场
- `/pricing` 价格方案
- `/resources` 资源中心
- `/contact` 联系我们
- `/terms` 服务协议
- `/privacy` 隐私政策

以上页面原位切换至 V3，不另建 V3 预览路由。`/home-v2` 保留原状，作为独立的第二版首页。

全站页面采用一致的浅薄荷背景和墨绿色品牌色，包括登录注册、账号恢复、`/workspace`、`/billing` 与 404；这些页面只进行视觉换肤，不更改表单、认证服务或业务流程。`/home-v2` 保留独立但同样为浅绿的主题。API、数据库与部署配置不在视觉改版范围内。不得改动认证、订单、支付、Designer SSO、项目配额、咨询保存或套餐定价规则。服务协议和隐私政策只统一视觉排版，不改动法律文本实质内容。

### 视觉方向

采用已选定的“忠实延续参考站”方向：

- 浅薄荷绿页面背景、墨绿强调色、深色正文与大留白。
- 使用白色内容卡片及业务看板示意，保持清楚的层级与克制的边框、圆角。
- 使用项目现有 Vizora AI Logo 素材，不以文字或临时图形替代。
- 桌面端建立完整的横向布局；平板与手机逐步堆叠，避免横向溢出。
- 尊重 `prefers-reduced-motion`，并保留清晰键盘焦点、语义化结构和可读对比度。

## 页面体验

### 首页

按参考站的产品叙事组织长页：

1. V3 导航与首屏：产品主张、需求输入框、场景示例选择和 CTA；搭配明确标记为概念示意/非实时数据的看板。
2. 从需求到交付的阶段说明，区分门户已实现、外部 Designer 集成和待验收事项。
3. 业务上下文与数据来源示意，表达指标口径、数据来源和应用结构之间的关系；不暗示本站已连接用户数据。
4. 六类应用场景及目标用户内容。
5. 产品当前能力与规划路线，显式区分已实现、外部集成、规划。
6. 联系 CTA 与统一页脚。

场景示例只切换本地概念示意并预填需求，不执行真实 AI 生成。提交需求沿用现有会话存储和导航行为：已登录用户进入工作台，匿名用户前往注册/工作台流程。

### 其他公开页面

- **产品能力：**保留现有能力分类及“已实现 / 外部集成 / 规划”等状态说明。
- **应用场景：**保留受众切换、场景导航及把场景需求带入项目的行为。
- **模板市场：**保留搜索、分类筛选、空结果、详情弹窗和使用模板创建项目的行为。模板是需求灵感，不是已部署应用。
- **价格方案：**继续使用真实 `/api/plans` 数据和既定价格/配额，保留套餐比较及购买入口。未接通能力标记为规划，不能作为套餐已交付权益。
- **资源中心：**保留章节锚点、账号/项目/Designer/计费/安全/部署等真实使用说明。
- **联系页面：**保留真实线索 API 提交及隐私同意；明确呈现提交中、成功和错误状态。
- **协议与隐私：**只调整版式和响应式呈现，不修改法律内容。

所有既有公开页面路由、导航入口、表单语义和页面操作继续可用；本次不新增后端 API 或 mock 数据回退。

价格页将“价格方案”命名为“价格”。API 载入失败时，仍展示已确认的标准参考金额和套餐权益，明确标记 API 服务不可用，保留重试与免费注册/企业咨询入口，并禁用 Creator/FDE 下单。参考价不用于创建订单，任何付费订单仍必须读取服务端实际套餐金额。首页页脚不展示“规划能力以功能标识为准 · 运营主体与法务信息待正式审核”提示行。

## 架构与数据流

- 在现有 Vue 3、TypeScript、Vue Router、Vite 结构内增量实现，不引入新框架、设计系统或数据模拟层。
- 所有非 `/home-v2` 路由共用浅绿色主题、导航/页脚与浅色状态；V2 仍使用独立导航/页脚和自包含样式。
- 页面级样式使用绿色主题变量和作用域，防止独立 V2 首页出现深色背景回归。
- 继续复用现有组件、API 客户端和路由：套餐从 API 加载，咨询提交到线索 API，项目/模板需求写入现有会话存储。
- 不信任浏览器价格，不从页面返回状态发放权益；不把门户 JWT 放入 URL；不把 Designer、SMTP 或支付配置未完成时呈现为成功状态。
- 对 API 失败、空结果、表单提交中、提交失败及成功状态沿用显式状态说明，禁止静默失败或成功形回退。

## 无障碍与响应式

- 导航链接、菜单、示例切换、搜索/筛选、弹窗和表单都可键盘操作。
- 移动导航保留现有关闭键盘行为和焦点恢复；弹窗继续提供明确标题、关闭操作和焦点语义。
- 输入错误和 API 错误通过可访问的提示元素呈现；成功/待处理状态可被辅助技术识别。
- 主要视口覆盖桌面、平板、手机窄屏，页面无非预期横向滚动。
- 动效在系统减少动态效果时关闭或降级。

## 验收标准

1. 九个范围内公开页面采用一致的 V3 视觉系统；Logo 来自现有素材。
2. 全部应用路由背景不使用蓝色；公开站、登录注册、账号恢复、工作台、账单和 404 使用浅绿/薄荷底色与墨绿文字/控件。`/home-v2` 保持独立布局但与主题色一致。
3. 首页示例切换、需求保存与匿名/登录用户导航符合现有项目流程，且没有真实生成的虚假表述。
4. 模板搜索、分类、详情和创建项目动作可用；应用场景需求能沿现有流程进入工作台或注册。
5. 价格以 API 数据为准，既定套餐金额、期限、配额及规划能力边界不变。
6. 联系表单仍使用真实 API，并正确展示 pending/success/error。
7. 桌面、平板、手机浏览器验证主要导航与操作，无横向溢出；键盘、焦点和减少动态效果行为符合要求。
8. 前端相关单元测试、类型检查和生产构建通过；任何外部服务验收状态均不因视觉改版而改变。

## 非目标

- 新增组织协作、发票、应用发布/运行、管理后台、真实实时数据或 AI 生成能力。
- 调整套餐/历史订单金额、认证策略、API 合同、支付与退款业务、Designer SSO 或部署拓扑。
- 通过静态展示或本地模拟宣称真实 SMTP、商户支付、外部 Designer、法务审核或生产部署验收完成。
