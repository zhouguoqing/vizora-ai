# Vizora AI V4 · 官网和商业化站点

基于旧版 Vue 3 + TypeScript / ASP.NET Core 10 / PostgreSQL 商业化骨架扩展。

## 页面清单
- `/` 长首页：hero、Prompt、应用预览、步骤、能力、用户、模板、套餐、FAQ、CTA
- `/features` 产品能力、`/solutions` 场景切换、`/templates` 模板搜索筛选
- `/pricing` 价格、`/resources` 资源、`/contact` 企业咨询（仅本地邮件客户端，尚未接销售系统）
- `/login`、`/register`、`/workspace`、`/billing`、`/terms`、`/privacy`

## 当前交付成熟度
新的官网和子页面为实际 Vue 源代码；既有 API 支付与用户管理使用前一版骨架。非完整的生产安全或真实资金上线验收版。无法直接宣称“已可对公众正式收款”。

注意：展示价格、指标、模板和插图是示意，未使用假客户 Logo 做背书；正式销售需要产品权益和法律文件审查。

参见原始 `README.md` 与 `RELEASE_GATE.md`。
